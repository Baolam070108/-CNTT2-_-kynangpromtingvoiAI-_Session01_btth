## 1. Sơ đồ Prompt Chaining

```text
Prompt ban đầu
-> Tìm hiểu LLM
-> Nhận diện ảo giác AI
-> Xây dựng Prompt CREATE
-> Tổng hợp thành cẩm nang
```
2. Các Prompt thành phần
Prompt 1:
Giải thích LLM hoạt động như thế nào, cách AI dự đoán từ và vai trò của Token.
Prompt 2:
Trình bày 3 cách nhận diện ảo giác AI, có ví dụ liên quan đến lập trình.
Prompt 3:
Tạo một Prompt mẫu theo cấu trúc CREATE để hỗ trợ sinh viên học lập trình C.
Prompt 4:
Tổng hợp 3 nội dung trên thành cẩm nang ngắn gọn, dễ hiểu.
3. Cẩm nang hoàn chỉnh
3.1. Cách AI hoạt động (LLM)
- LLM là mô hình ngôn ngữ lớn được huấn luyện từ dữ liệu.
- AI tạo câu trả lời bằng cách dự đoán Token tiếp theo.
- Token là đơn vị dữ liệu dùng để xử lý văn bản.
3.2. Ba cách nhận diện ảo giác AI
Ảo giác AI là hiện tượng AI đưa ra thông tin sai nhưng trình bày rất tự tin.
1. Kiểm tra nguồn thông tin và đối chiếu tài liệu.
2. Chạy thử code để kiểm tra kết quả.
3. Yêu cầu AI giải thích và so sánh với nguồn khác.
3.3. Cấu trúc Prompt CREATE
- C – Context: Bối cảnh.
- R – Request: Yêu cầu.
- E – Explanation: Giải thích.
- A – Action: Các bước thực hiện.
- T – Tone: Giọng điệu.
- E – Extras: Yêu cầu bổ sung.
